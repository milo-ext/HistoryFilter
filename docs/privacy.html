HistoryFilter Privacy Policy

Effective date: November 7, 2026 · Publisher: Milo · Contact: m66054198@gmail.com

English中文

In short: HistoryFilter works entirely inside your browser. It has no server, analytics, advertising, or telemetry, and it never sends your browsing history, rules, or logs to the publisher or anyone else.

HistoryFilter lets you create URL rules that remove or rewrite entries in your browser history. This policy covers the Chrome and Firefox versions of the extension.

Data the extension uses

  • Browsing history URLs and visit metadata. With the browser's history permission, the extension reads URLs as the browser records visits and, when you request a manual scan, searches history in the range you choose. It uses those URLs only to match your rules. A matching delete rule removes all visits to that URL. A matching normalize rule adds the target URL as a new history entry and removes all visits to the original URL.
  • Your rules. Rule names, URL patterns, actions, options, and template identifiers are stored in extension storage on your device. You can edit, disable, or delete them at any time. A pattern, domain, or target URL you enter may itself be information you consider sensitive.
  • Rule export and import files. Export creates a JSON file containing your rules and saves it through the browser's normal download flow. It contains no browsing history, cleanup plans, or activity logs, and the extension does not send it anywhere. Import reads only the file you select, checks its rules in the page, and saves the accepted rules locally; no copy of the file is kept. Once exported, the file is yours to store or share.
  • Interface language. Your choice of English or Simplified Chinese is saved in extension storage in this browser profile. A URL typed into the rule tester is checked against your rules in the open page only; it is not added to history or saved.
  • Manual cleanup preview. A preview temporarily stores a plan with the matched URLs, target URLs, actions, and a snapshot of your rules in extension session storage, and shows up to 50 example URLs for review. The plan is removed when you execute or cancel it, create a new preview, or the browser clears session storage (browser restart, or extension reload, update, or disable). A plan can be executed only once.
  • Activity logs. Up to 100 entries are kept in extension storage. Each has a timestamp, an action and result code, and possibly numeric totals. Logs contain no URLs, paths, query strings, or free-form error text. You can clear them on the options page.

Sharing and retention

HistoryFilter has no developer-operated server and uses no analytics, advertising, or telemetry services. It does not sell, transfer, or share any data. Rules and activity logs stay on your device until you change or clear them or remove the extension. Cleanup plans are temporary as described above.

Browser history sync is controlled by your browser, independently of this extension. If enabled, history changes may propagate to other devices. HistoryFilter does not disable or manage that synchronization.

Permissions

  • history: read and change browsing history according to your rules.
  • storage: save rules, language choice, and activity logs locally, and hold a temporary cleanup plan.

Rule export and import use the browser's standard download and file picker and need no additional permission.

Store disclosures

The Firefox version declares that it collects no data (data_collection_permissions: none). The Chrome version behaves the same way.

Chrome Web Store Limited Use

HistoryFilter's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Browsing activity is used only to provide the extension's history-filtering features described above. It is not transferred to the publisher or third parties, used for advertising or credit decisions, or made available for human review.

Changes

If the way HistoryFilter handles data changes, this policy will be updated before the changed version is released, and the effective date above will change.

HistoryFilter 隐私政策（中文）

生效日期：2026 年 11 月 7 日 · 发布者：Milo

简而言之：HistoryFilter 的所有处理都在你的浏览器内完成。它没有服务器，不使用分析、广告或遥测服务，也从不把你的浏览历史、规则或日志发送给发布者或任何第三方。

HistoryFilter 允许你创建 URL 规则，删除或改写浏览器历史记录中的条目。本政策适用于该扩展的 Chrome 和 Firefox 版本。

扩展使用的数据

  • 浏览历史 URL 及访问信息。通过浏览器的 history 权限，扩展会在浏览器记录访问时读取 URL；当你手动发起扫描时，会在你选择的时间范围内搜索历史记录。这些 URL 只用于匹配你的规则。命中“删除”规则时，会删除该 URL 的全部访问记录；命中“净化”规则时，会把目标 URL 作为新的历史条目写入，并删除原 URL 的全部访问记录。
  • 你的规则。规则名称、URL 匹配条件、处理方式、选项和模板标识保存在你设备上的扩展存储中，你可以随时编辑、停用或删除。你输入的匹配条件、域名或目标 URL 本身可能包含你认为敏感的信息。
  • 规则导出与导入文件。“导出”会生成一个包含你的规则的 JSON 文件，通过浏览器的常规下载流程保存。文件中不含浏览历史、清理计划或活动记录，扩展也不会把它发送到任何地方。“导入”只读取你选择的文件，在页面内校验规则后把通过校验的规则保存在本地，不保留文件副本。导出后的文件由你自行保管或分享。
  • 界面语言。你选择的中文或英文界面保存在当前浏览器配置的扩展存储中。在规则测试框中输入的 URL 只在打开的页面内与规则比对，不会写入历史，也不会被保存。
  • 手动清理预览。预览时，扩展会在扩展会话存储中临时保存一份计划，包含命中的 URL、目标 URL、处理方式和规则快照，并最多展示 50 条示例 URL 供你核对。执行或取消计划、重新预览，或浏览器清空会话存储（重启浏览器，或重新加载、更新、停用扩展）时，计划会被移除。每份计划只能执行一次。
  • 活动记录。扩展存储中最多保留 100 条记录，每条包含时间、动作与结果代码，以及可能的数字统计。记录中不含 URL、路径、查询参数或自由文本错误信息。你可以在设置页面清空活动记录。

共享与保留

HistoryFilter 没有开发者运营的服务器，不使用分析、广告或遥测服务，不出售、转移或共享任何数据。规则和活动记录会保留在你的设备上，直到你修改、清空它们或移除扩展。清理计划按上文所述临时保存。

浏览器历史同步由浏览器独立管理。开启同步时，历史变更可能传播到其他设备；HistoryFilter 不会关闭或管理浏览器同步。

权限

  • history：按你的规则读取和修改浏览历史。
  • storage：在本地保存规则、语言选择和活动记录，并临时保存清理计划。

规则导出和导入使用浏览器标准的下载和文件选择功能，不需要额外权限。

商店声明

Firefox 版本声明不收集任何数据（data_collection_permissions: none），Chrome 版本的行为相同。

Chrome 网上应用店有限使用声明

HistoryFilter 对从 Chrome API 获取的信息的使用，遵守 Chrome 网上应用店用户数据政策，包括其中的“有限使用”要求。浏览活动仅用于提供上文所述的历史过滤功能，不会转移给发布者或第三方，不会用于广告或信用评估，也不会供人工查看。

变更

如果 HistoryFilter 处理数据的方式发生变化，会在发布相应版本之前更新本政策，并同步更新页首的生效日期。
