# Security

Report suspected security vulnerabilities privately to [m66054198@gmail.com](mailto:m66054198@gmail.com).

Include the HistoryFilter and browser versions, reproduction steps using synthetic URLs, the expected behavior, and the potential impact. Remove passwords, tokens, and other personal information from any examples or attachments.

Do not post security-sensitive details or real browsing history in public GitHub Issues. Do not attach full rule exports or browser profiles. Ordinary bugs can be reported through [GitHub Issues](https://github.com/milo-ext/HistoryFilter/issues) using synthetic examples.
