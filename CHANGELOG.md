# Changelog

## 1.0.0 — 2026-11-07

Initial desktop release for Chrome and Firefox.

- Ordered URL rules with domain, path, query-key and restricted regular-expression matching.
- Automatic history deletion and URL normalization, with optional starting templates.
- Manual history cleanup with an impact preview and explicit confirmation.
- Local JSON rule import/export and activity summaries without saved history URLs.
- English and Simplified Chinese settings, local URL testing, and light/dark appearance.
- Local processing with only history and storage permissions; no analytics or telemetry.

Deleting history is permanent. New installations start with the bundled rule disabled.
